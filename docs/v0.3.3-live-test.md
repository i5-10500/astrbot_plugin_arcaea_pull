# v0.3.3 闪传路由修复复测清单

v0.3.2 实机测试已证明 APK 下载与真实性验证正常，但真实 APK 分发在
`create_flash_task` 阶段得到空错误文本。源码核对确认插件误把 AstrBot 内部平台任务
UUID 当成 OneBot `self_id`。v0.3.3 改为读取 aiocqhttp 当前反向 WebSocket 连接中的
真实机器人 QQ 号，并保证无文本异常仍显示异常类型。

## 最小复测

- [ ] 安装后插件版本显示 `0.3.3`。
- [ ] NapCat 反向 WebSocket 已连接；`flash_transfer_self_id` 留空（单机器人），或填写
  当前机器人真实 QQ 号（多机器人）。
- [ ] `/apull flash_test` 成功，测试群收到小型闪传探针。
- [ ] `/apull distribute` 成功，测试群收到 VERIFIED APK 闪传。
- [ ] 再次执行 `/apull distribute` 显示 skipped，群内不重复收到 APK。
- [ ] 重启 AstrBot 后再次分发仍显示 skipped。

若仍失败，请记录完整插件错误和同一时间段的 NapCat 日志。修复后错误至少应包含
`ApiNotAvailable`、`TimeoutError`、`ActionFailed` 等异常类型，不应再只显示
`NapCat action 'create_flash_task' raised:`。
